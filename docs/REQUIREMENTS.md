> Áp dụng cho **mọi** thay đổi: code mới, sửa lỗi, thêm section, đổi nội dung — dù do người hay AI agent thực hiện.

## R0. Quy trình trước khi làm bất cứ việc gì

1. Đọc Phần A của file này (ít nhất phần liên quan) trước khi code.

4. Khi xong: chạy `npm run lint` và `npm run build`; đối chiếu checklist mục 10 (Phần A) cho phần đã chạm vào.
